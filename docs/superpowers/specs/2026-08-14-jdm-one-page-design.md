# JDM 국제 간사 사역 공유 한 페이지 디자인

## 목표

기존 기획서의 핵심 메시지인 "세계 곳곳의 사역 현장을 보고 함께 기도한다"를 초보 방문자도 한 번에 이해할 수 있는 정적 한 페이지로 실험한다. 첫 버전은 실제 로그인, 파일 업로드, 데이터베이스 없이 샘플 콘텐츠와 브라우저 내 상호작용만 제공한다.

## 범위

- 페이지 상단에 JDM 국제 사역 공유라는 이름과 짧은 소개를 표시한다.
- 대표 영역에 현재 사역을 설명하고 갤러리로 이동하는 버튼을 둔다.
- 지역 필터(전체, 아시아, 아프리카, 유럽, 미주)를 누르면 샘플 카드가 즉시 필터링된다.
- 사진 카드를 누르면 큰 이미지와 설명이 있는 모달을 연다.
- "사진 올리기" 버튼은 실제 전송 대신 초보자에게 다음 단계임을 알려주는 간단한 업로드 안내 패널을 연다.
- 모바일과 데스크톱에서 읽기 쉽고 조작 가능해야 한다.

## 제외 범위

- Firebase, 로그인, 권한 관리
- 실제 이미지 저장 및 서버 업로드
- CMS, Word 문서 변환, 게시판 백엔드
- 국가별 라우팅과 검색

## 화면 구성

1. 헤더: 로고 텍스트, "사진 올리기" 버튼
2. 히어로: 작은 라벨, 큰 제목, 설명, "사역 둘러보기" 버튼, 현재 샘플 사진 묶음
3. 갤러리: 섹션 제목, 지역 필터, 반응형 카드 격자
4. 업로드 안내: 사진 업로드는 다음 단계라는 메시지와 세 단계 사용 안내
5. 푸터: JDM 소개 문구와 현재 버전 안내

## 시각 방향

밝은 아이보리 배경, 짙은 잉크색 글자, 숲색 포인트와 따뜻한 주황색 보조색을 사용한다. 둥근 카드와 넉넉한 여백으로 친근하게 만들되, 과도한 장식이나 복잡한 대시보드 형태는 피한다. 사진은 Unsplash의 원격 샘플 URL을 사용하고, 각 카드에 지역·제목·짧은 설명을 명확히 표시한다.

## 상호작용 및 오류 처리

- 필터 선택 시 선택 상태를 버튼의 `aria-pressed`로 표시한다.
- 카드 상세 모달은 닫기 버튼, 배경 클릭, `Escape` 키로 닫을 수 있다.
- 이미지 로드 실패 시 카드의 대체 배경과 대체 텍스트가 남아 페이지 흐름이 깨지지 않는다.
- 업로드 안내는 실제 제출 버튼을 제공하지 않고, 아직 실험 단계임을 분명히 표시한다.

## 기술 및 검증

Vite 기반의 최소 React 앱으로 구성한다. 컴포넌트는 페이지 안에서 이해하기 쉬운 수준으로 유지하고 별도 상태 관리 라이브러리는 사용하지 않는다. `npm run build`로 프로덕션 빌드를 검증하고, 가능하면 개발 서버에서 필터·모달·모바일 레이아웃을 확인한다.
