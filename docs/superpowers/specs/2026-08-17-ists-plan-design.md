# 2026 ISTS 계획서 디자인

## 목표

기존 4쪽 PDF의 내용을 공식 행사계획서 웹 페이지로 재구성한다. 화면에서는 읽기 쉽고 세련된 문서로 보이며, 브라우저의 인쇄 기능으로 PDF로 저장했을 때에도 페이지 구성이 유지되도록 한다.

## 시각 방향

- 차분한 네이비를 기본색으로 사용하고 골드 색상을 강조색으로 사용한다.
- 표지에는 행사명, 주제, 일정과 장소를 집중 배치한다.
- 본문은 목적, 요람, 참가자, 일정, 프로그램, 운영진, 예산 순서의 섹션으로 구성한다.
- 참가자·예산은 표로, 목적·프로그램·운영진은 카드와 목록으로 정리한다.
- 모바일에서는 표를 가로 스크롤할 수 있고, 인쇄 시에는 표와 섹션이 잘리지 않도록 페이지 나눔을 제어한다.

## 내용 정리 원칙

- 참가자 20명과 5개국 정보는 원문을 기준으로 유지한다.
- 일정의 `15:00-5:00`은 문맥상 `15:00-17:00`으로 교정한다.
- 프로그램에 기재된 현지사역 소개 10개 항목과 일정표의 실제 배치를 일치시킨다.
- 예산 식비의 25명 계산은 참가자 20명 외 운영진을 포함한 행사 전체 식수 기준으로 설명한다.
- 원문에 없는 참가자·강사·금액은 추가하지 않는다.

## 구현 범위

- `app/page.tsx`: ISTS 계획서 전체 화면과 데이터
- `app/globals.css`: 화면·모바일·인쇄용 스타일
- 기존 API와 의존성은 변경하지 않는다.

## 검증

- TypeScript/Next.js 빌드가 성공해야 한다.
- 데스크톱과 좁은 화면에서 주요 섹션이 읽혀야 한다.
- 인쇄 미리보기에서 표가 화면 밖으로 잘리지 않고 섹션 단위로 자연스럽게 나뉘어야 한다.
