# 2026 ISTS Plan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the temporary landing page with a polished, responsive 2026 ISTS event plan that can be printed to PDF.

**Architecture:** Keep the existing Next.js App Router entry point and render the plan from local typed data in `app/page.tsx`. Put all visual behavior in `app/globals.css`, including responsive table handling and print-specific page breaks. No new dependencies or APIs are needed.

**Tech Stack:** Next.js 16, React 19, TypeScript, CSS media queries, CSS print rules.

**Spec:** `docs/superpowers/specs/2026-08-17-ists-plan-design.md`

## Global Constraints

- Use a calm navy and gold official-event visual direction.
- Preserve the source participant data and do not invent people, amounts, or activities.
- Correct `15:00-5:00` to `15:00-17:00` and explain the 25-person meal count as including staff.
- Support desktop, mobile, and browser print-to-PDF output.
- Do not change the existing API or add dependencies.

### Task 2: Add Screen, Responsive, and Print Styling

**Files:**
- Modify: `app/globals.css`

**Interfaces:**
- Styles the class names produced by `app/page.tsx`.
- Provides print behavior through `@media print` without requiring JavaScript.

- [ ] **Step 1: Add the visual tokens and base layout**

Define CSS variables for navy, muted navy, gold, cream, ink, and borders. Add the page background, readable Korean/system font stack, constrained document width, section spacing, typography, cards, pills, and table styling.

- [ ] **Step 2: Add responsive behavior**
